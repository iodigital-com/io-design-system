## Summary
Dark theme values in app.css include hardcoded color values not represented in docs/tokens.json.

## Evidence
- io-components/src/global/app.css dark theme block (~lines 320-355)
- includes multiple hex and rgba values without docs/tokens.json counterparts

## Impact
- undocumented theme behavior
- token source of truth drift

## Proposed Fix
Add dark theme token representation to docs/tokens.json (or approved companion token source) and map app.css values to those tokens.

## Acceptance Criteria
- all dark theme values resolve from documented tokens
- no orphan hardcoded dark theme color values remain
- docs explain theme token model

## Validation Steps
- npm run build
- verify token docs and app.css are aligned

## Out of Scope
- changing the chosen dark palette itself
