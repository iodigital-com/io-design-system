## Summary
Toast styles contain hardcoded dimensions and breakpoint values not aligned with token governance.

## Evidence
- io-components/src/components/io-toast/io-toast-styles.ts:13 uses @media (max-width: 480px)
- io-components/src/components/io-toast-item/io-toast-item-styles.ts:26,39,47,50,60 use fixed px/rem offsets and sizes

## Impact
- responsive behavior and spacing become hard to govern centrally
- inconsistent brand behavior across breakpoints

## Proposed Fix
Tokenize toast breakpoint and dimensional offsets or document approved exceptions with rationale.

## Acceptance Criteria
- toast and toast-item style literals are tokenized or explicitly allowlisted
- responsive breakpoint strategy is consistent with system breakpoints
- snapshots/visual checks updated

## Validation Steps
- npm run build
- storefront toast visual QA at mobile + desktop widths

## Out of Scope
- redesign of toast component interaction behavior
