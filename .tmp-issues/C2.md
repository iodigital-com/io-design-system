## Summary
docs/tokens.json contains entries that are not surfaced as CSS custom properties in app.css.

## Evidence
- tokens for tertiary/secondary palettes, component.carousel.*, component.accordion.*, card tokens, typography secondary/utility, motion fastest/micro are not reflected as --io-* vars

## Impact
- docs-only tokens create false implementation confidence
- dead spec debt accumulates

## Proposed Fix
Expose missing high-value tokens as CSS vars or explicitly deprecate unused token entries with rationale.

## Acceptance Criteria
- each tokens.json entry is either implemented in app.css or marked deprecated/unused with governance policy
- inventory report attached and reviewed

## Validation Steps
- compare token keys vs app.css var keys
- npm run governance:check

## Out of Scope
- introducing new design language values
