## Summary
Vue wrapper IoModal has duplicate 'open' entries in defineContainer mapping.

## Evidence
- io-components-vue/src/components.ts:101 and :105 both include 'open' in IoModal mapping array

## Impact
- wrapper mapping ambiguity and maintainability risk
- potential runtime confusion for prop/event bridging

## Proposed Fix
Ensure generated Vue mapping deduplicates identifiers and add a guard check in wrapper generation QA.

## Acceptance Criteria
- IoModal mapping contains unique entries only
- dedupe guard prevents recurrence
- Vue wrapper build and type-check pass

## Validation Steps
- npm run build:wrapper:vue
- npm run build

## Out of Scope
- changing modal API semantics outside dedupe fix
