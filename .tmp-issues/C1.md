## Summary
app.css contains undocumented --io-* CSS variables not represented in docs/tokens.json.

## Evidence
- global file: io-components/src/global/app.css
- examples include color hover aliases, semantic aliases, layout vars, component vars, z-index aliases
- audit identified ~20+ vars lacking token definitions

## Impact
- runtime-only variables bypass token governance
- harder onboarding and maintenance

## Proposed Fix
Create a reconciliation pass: document each runtime var in docs/tokens.json or remove/alias it to documented tokens.

## Acceptance Criteria
- complete inventory of runtime vars vs token docs
- every runtime var is documented, aliased, or removed
- governance check can detect future drift

## Validation Steps
- run reconciliation script and attach output to issue
- npm run governance:check

## Out of Scope
- changing variable naming strategy (tracked separately)
