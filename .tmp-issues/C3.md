## Summary
Token naming diverges between docs/tokens.json paths and app.css variable names in several places.

## Evidence
Examples:
- color.semantic.red vs --io-color-error-dark
- color.system.interactiveBlue vs --io-color-system-blue
- color.focus.darkRed/lightPink vs --io-focus-inner/--io-focus-outer
- form.checkbox.borderRadius vs --io-checkbox-radius

## Impact
- weak discoverability and mapping automation
- higher chance of duplicate or conflicting tokens

## Proposed Fix
Define canonical mapping rules and introduce aliases/deprecations to converge naming over time.

## Acceptance Criteria
- canonical mapping doc implemented in code comments/docs
- mismatches either fixed or explicitly aliased
- lint/validation step catches future naming divergence

## Validation Steps
- run naming consistency audit and include result in PR

## Out of Scope
- changing existing public CSS API without migration path
